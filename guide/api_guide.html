API 密钥配置指南

聊天、网页/链接总结、AI 设计正则和图片分析需要您自行配置 AI 服务。仅使用“提取全文”、正则预览与复制时不需要 API 密钥。本指南介绍当前配置字段；服务商控制台界面可能变化，请以其官方文档为准。

重要提示：API 密钥非常敏感，请勿分享或粘贴到问题报告中。配置（包括密钥）保存在 chrome.storage.sync，可能由 Chrome 同步到登录同一 Google 账户的其他浏览器；插件开发者不运营中转服务器，也无法读取您的密钥。密码输入框仅隐藏屏幕显示，不代表应用层加密。

获取 Google Gemini API 密钥

  1. 访问 Google AI for Developers 官方网站。
  2. 按照网站当前的 API Key 创建流程登录并创建密钥。服务商可能要求先选择或创建一个项目。
  3. 创建后立即复制密钥，并在服务商控制台中按需设置额度、模型访问和密钥限制。

获取 OpenAI 兼容 API 密钥

此方法适用于 OpenAI 官方 API 以及任何与 OpenAI API 格式兼容的第三方服务。

  1. 访问您选择的 AI 服务提供商网站（例如 OpenAI Platform）。
  2. 按照服务商当前文档进入 API Key 管理页并创建密钥。网页聊天订阅与 API 额度通常是不同产品，请确认 API 账户可用。
  3. 创建后立即复制密钥，并记录服务商给出的 Chat Completions Endpoint 和可用模型 ID。

在插件中配置密钥

  1. 在浏览器工具栏中，右键点击“智能侧边栏助手”的图标，然后选择“选项”。
    [截图：显示在浏览器工具栏右键点击插件图标并选择“选项”]
  2. 在打开的“API 配置管理”页面中，填写表单：
    • 配置名称: 给这个配置起一个易于识别的名字，如 “我的 Gemini 密钥”。
    • API 密钥: 粘贴您刚刚从服务商处复制的密钥。
    • API 类型: 根据您的密钥类型选择 "Google Gemini" 或 "OpenAI 兼容 API"。
    • API Endpoint URL: (仅当类型为 OpenAI 兼容时需要) 填写服务商给出的完整 Chat Completions 地址，例如 https://api.example.com/v1/chat/completions，而不是控制台首页或 API 根目录。
    • 模型名称: 填写服务商当前支持的准确模型 ID，不要使用控制台中的展示名称代替。
    [截图：显示插件的 API 配置页面，并高亮各个输入框]
  3. 先点击“测试连接”。测试请求不会保存配置；成功后仍需点击“保存配置”。
  4. 保存后，请确保想使用的配置旁显示“(当前活动)”。如果不是，请点击“设为活动”。测试连接使用非流式请求；OpenAI 兼容服务的聊天还必须支持 stream: true 的 SSE 响应。

配置完成后即可打开侧边栏。若测试成功但聊天失败，请检查 Endpoint 是否返回 OpenAI Chat Completions 兼容的 SSE data: 事件；若出现 401/403、429 或 5xx，请分别检查密钥权限、额度和服务商状态。
