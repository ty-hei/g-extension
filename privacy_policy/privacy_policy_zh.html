智能侧边栏助手 (Smart Sidebar Assistant) 隐私政策

欢迎您使用“智能侧边栏助手”（以下简称“本插件”）。我们深知隐私对您的重要性，并会尽全力保护您的个人信息安全。本隐私政策旨在向您说明本插件如何收集、存储、使用和保护您的信息。

请在使用本插件前，仔细阅读并充分理解本政策。

1. 我们收集的信息

重要提示：功能数据在您的浏览器内存或浏览器存储中处理；当您主动总结网页、总结链接、发送聊天消息或分析图片时，相关数据会由浏览器直接发送到目标网站或您配置的第三方 AI 服务。插件开发者不运营中转服务器，也无法查看您的网页内容或 API 密钥。

用户配置信息

  • API 配置: 您在选项页面添加的 API 配置，包括配置名称、API 密钥、API 类型、API Endpoint URL（如果适用）以及模型名称。此信息存储在 chrome.storage.sync 中，以便在您登录同一 Google 账户的多个 Chrome 浏览器间同步。
  • 活动配置ID: 用于标识当前正在使用的 API 配置。此信息存储在 chrome.storage.sync 中。
  • 正则工具设置: 是否启用正则工具、正则表达式、flags 和正文/可见全文模式存储在 chrome.storage.sync 中。网页原文和匹配结果不包含在这些同步设置中。

用户生成内容与历史记录

  • 对话历史: 最近最多 50 个普通聊天会话。此信息存储在您本地浏览器的 chrome.storage.local 中。
  • 已存档对话: 您手动存档的对话或问答对。此信息同样存储在 chrome.storage.local 中。
  • Prompt 模板: 您在管理页面创建和保存的 Prompt 模板。此信息存储在 chrome.storage.local 中。

为实现功能而临时处理的信息

  • 当前网页内容: “总结当前网页”会优先使用 Readability 提取正文，并将段落、块元素和换行边界保留为多行纯文本；失败时回退到页面可见文本，再将结果发送给您配置的 AI 服务。“提取全文”读取页面的可见 body.innerText 并先作为本地引用，不会因提取动作本身调用 AI。
  • 链接内容: 当您拖拽链接或通过右键菜单请求总结链接时，插件会打开一个非活动的临时后台标签页。目标网站会像普通访问一样收到网络请求，并可能使用您已有的登录状态、Cookie 和自身的分析工具。插件在页面加载后使用 Readability 提取正文（失败时回退到可见文本），随后关闭临时标签页。最多同时运行 3 个链接提取任务；超出的请求会被拒绝，不会继续打开标签页。
  • 正则提取: 正则源文本、表达式执行和匹配预览均在本地 Web Worker 中处理，并设有 1 秒执行超时和结果上限。原文与匹配结果不会因预览或复制而发送给第三方；若您使用“设计正则”并随后主动发送生成的请求，所含网页文本会发送到当前 AI 服务，并可能像普通聊天一样携带最近的对话上下文。该请求不会自动采用页面/链接摘要的历史隔离与网页安全指令。
  • 选中的文本或图片: 只有当对应浏览器窗口的插件侧边栏处于打开状态时，网页选中文本才会被获取并显示为引用；侧边栏关闭后不捕获选区。图片 URL 仅在您使用图片分析右键菜单时获取；生成预览时可能立即向图片源站请求资源。点击发送后，浏览器会再次执行受 10 MiB 大小、图片类型和 30 秒超时限制的抓取，再把图片数据发送给当前 AI 服务。

2. 我们如何使用您的信息

我们使用您的信息完全是为了实现插件的各项功能，具体如下：

  • 建立与 AI 服务的连接: 您的 API 密钥和配置信息被用来直接从您的浏览器向您选择的第三方 AI 服务（如 Google Gemini 或 OpenAI 兼容 API）发送请求。
  • 执行您的指令: 您主动提交的文字、引用、页面/链接总结内容或图片数据，会作为请求的一部分发送给 AI 服务，以获得您期望的回复（如总结、翻译、分析结果等）。仅执行本地全文提取、正则预览或复制匹配结果不会发送数据给 AI。
  • 维护对话上下文: 普通聊天和在存档中继续对话会携带最近的对话历史，使 AI 能够理解近期交流；页面/链接摘要请求不会携带既有对话历史，并会附加将网页内容视为不可信数据的安全指令。
  • 资源上限: 每个提取文本字段最多保留 200,000 字符；发送给 AI 的文本会在 120,000 个源字符后截断；普通聊天请求最多携带最近 40,000 字符的历史上下文；下载处理的图片上限为 10 MiB。正则预览最多返回 1,000 个匹配和 100,000 个结果字符。链接任务会话数据使用 7 MiB 内部预算，并在打开标签页前预留结果空间；侧边栏与存档页的流式 AI 请求总时限为 2 分钟，连续 30 秒无流数据时终止。
  • 提供个性化功能: Prompt 模板帮助您快速执行常用任务。存档和历史记录功能方便您回顾重要的信息。

浏览器权限用途

  • 兼容性: v1.4.0 要求 Chrome 120 或更高版本，以支持并统一验证侧边栏、会话存储、定时任务和 Web Worker 工作流。
  • activeTab 与 scripting：在您指定的标签页中按需运行网页提取器。
  • tabs：定位正确的窗口/标签页，并创建、监控和关闭链接提取所需的非活动临时标签页。
  • alarms：在后台 Service Worker 休眠期间仍可执行链接任务超时、领取租约/重试唤醒与清理。
  • storage：保存同步设置、本地聊天记录和临时链接任务。
  • contextMenus 与 sidePanel：提供链接/图片右键操作并显示侧边栏界面。
  • <all_urls> 主机权限：允许在您选择的任意网页上运行提取及可选的选区/链接功能，并连接您自行配置的 OpenAI 兼容 Endpoint。该权限本身不会自动发送网页内容。

3. 信息的存储与安全

  • 本地存储: 您的对话历史、存档和 Prompt 模板都通过 chrome.storage.local API 存储在您的本地计算机上。这意味着除非您手动操作，否则这些信息不会离开您的设备。
  • 同步存储: 您的 API 配置信息（包括 API 密钥）通过 chrome.storage.sync API 存储，并可能在您登录同一 Google 账户的浏览器间同步。开发者无法访问这些信息；插件没有额外实施应用层加密，密码输入框仅用于隐藏屏幕显示。
  • 会话存储: 链接任务的 URL、标题、状态及提取结果会暂存在 chrome.storage.session 中，并受 7 MiB 内部预算约束，以便侧边栏打开后领取结果及后台恢复任务。“领取”本身不会删除记录；AI 成功返回非空响应后，侧边栏才会确认并删除任务；若 AI 发送失败，则释放领取状态并由定时任务稍后唤醒重试。仍未删除的完成或失败记录会在提取结束约 10 分钟后尝试清理，有效的领取或重试等待会推迟清理。
  • 安全措施: 我们采取了行业标准的做法来保护您的信息安全。例如，API 密钥在选项页的输入框中显示为密码（type="password"），模型生成的 Markdown 会先经过 HTML allowlist 清洗再显示。插件不包含任何可能将您的数据发送给开发者的代码。

4. 信息共享与披露

插件开发者不会出售您的个人信息，也不会自行向无关第三方披露。您主动使用联网功能时，浏览器会按您的指令向所选 AI 服务、目标网站或图片源站传输实现该功能所需的数据。

本插件的核心工作模式是作为您与第三方 AI 服务之间的“桥梁”。当您使用本插件时，您需要知晓：

  • 您请求处理的数据（如网页内容、您输入的文字等）以及您的部分配置信息（如 API 密钥），将由您的浏览器直接发送至您所配置的第三方 AI 服务提供商（例如 Google 或其他 OpenAI 兼容服务商）。
  • 链接总结会让临时后台标签页直接访问目标网站；该网站会按照自己的隐私政策处理请求、Cookie、登录状态和访问日志。
  • 这些第三方服务提供商有其独立的隐私政策和数据处理惯例。我们强烈建议您在使用前查阅其相关的隐私政策。本插件不对任何第三方服务的数据处理行为负责。

再次强调，您的任何数据都不会经过我们的服务器。

5. 您的权利与选择

您对您的信息拥有完全的控制权：

  • 访问与修改: 您可以随时在插件的“选项”页面查看、修改或删除您的 API 配置。您也可以在“管理 Prompt”页面管理您的模板。
  • 本地处理选择: 您可以在不配置 API 的情况下使用可见全文提取和正则预览/复制。关闭侧边栏即可停止选区捕获。
  • 删除:
    • 您可以通过侧边栏中的“清除所有历史”按钮永久删除普通聊天历史；已存档对话不会被该按钮删除。
    • 您可以在“已存档对话”页面单独删除某条存档，或清空所有存档。
    • 卸载本插件将清除所有存储在 chrome.storage.local 中的数据（包括历史记录、存档和模板）。

6. 儿童隐私

本插件不适用于13岁以下的儿童。我们不会有意收集任何来自13岁以下儿童的个人身份信息。

我们可能会适时更新本隐私政策。任何变更我们都会在本页面上发布新版本。我们建议您定期查阅，以了解最新的隐私政策。
