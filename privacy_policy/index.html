Welcome to Smart Sidebar Assistant (hereinafter referred to as "this extension"). We value your privacy and are committed to protecting your personal information.

Please read this Privacy Policy carefully and fully understand its terms before using this extension.

1. Information We Collect

Important Note: Feature data is processed in browser memory or browser storage. When you choose to summarize a page or link, send a chat message, or analyze an image, the relevant data is sent directly by your browser to the target website or third-party AI service you configured. The extension developers operate no relay server and cannot view your page content or API keys.

User Configuration Information

  • API Configurations: The API settings you add on the options page, including Configuration Name, API Key, API Type, API Endpoint URL (if applicable), and Model Name. This information is stored in chrome.storage.sync to be synced across your Chrome browsers where you are logged into the same Google account.
  • Active Configuration ID: An identifier for the currently active API configuration. This is also stored in chrome.storage.sync.
  • Regex Tool Settings: The enabled state, pattern, flags, and reader/full-visible-text mode are stored in chrome.storage.sync. Page source text and match results are not part of these synced settings.

User-Generated Content and History

  • Conversation History: Up to the 50 most recent ordinary chat sessions. Conversations are stored as separate indexed records in chrome.storage.local, with a 512 KiB per-record limit and 7 MiB history-store budget.
  • Archived Chats: Up to 200 conversations or Q&A pairs that you manually archive, using the same per-record and store budgets in a separate chrome.storage.local index.
  • Prompt Templates: The prompt templates you create and save on the management page. This is stored in chrome.storage.local.

Information Processed for Functionality

  • Current Page Content: “Summarize Current Page” first uses Readability to extract the main article while preserving paragraph, block, and line-break boundaries as multiline plain text, falls back to visible page text if necessary, and sends the result to your configured AI service. “Extract Full Text” reads visible body.innerText and initially keeps it as a local quote; extraction by itself does not call an AI service.
  • Link Content: When you drag a link or request a link summary from the context menu, the extension opens an inactive temporary background tab. The target site receives a normal page request and may use your existing login state, cookies, and its own analytics. After loading, the extension extracts the article with Readability (falling back to visible text) and then closes the temporary tab. At most three link extractions run concurrently; additional requests are rejected instead of opening more tabs.
  • Regex Extraction: Regex source text, execution, and match preview are processed locally in a Web Worker with a one-second timeout and bounded output. Previewing or copying does not send source or matches to a third party. If you use “Design Regex” and then choose to send the prepared request, its page text is sent to the active AI service and may include recent conversation context like an ordinary chat request. It does not automatically receive the history isolation or webpage-safety instruction used for page/link summaries.
  • Selected Text or Images: Page selections are retrieved and shown as quotes only while this extension's sidebar is open in the corresponding browser window; selection capture stops when the sidebar is closed. An image URL is retrieved only when you invoke the image-analysis context menu action; rendering the preview may immediately request the image host. After you send, the browser performs another fetch subject to the 10 MiB size, image-type, and 30-second timeout checks, then submits the image data to the active AI service.

2. How We Use Your Information

We use your information solely to enable the features of the extension:

  • Connecting to AI Services: Your API key and configuration details are used to send requests directly from your browser to the third-party AI service you have chosen (e.g., Google Gemini or an OpenAI-compatible API).
  • Executing Your Instructions: Text, quotes, page/link summary content, or image data that you actively submit is sent as part of a request to the AI service to get the desired response (e.g., a summary, translation, or analysis). Local full-text extraction, regex preview, and copying matches do not send data to AI.
  • Maintaining Conversation Context: Your conversation history is used to build the context for ordinary chat and continued archived conversations. Page/link summary requests exclude existing conversation history and add a safety instruction that treats webpage content as untrusted data.
  • Resource Limits: Each extracted text field is limited to 200,000 characters. AI-bound text is truncated after 120,000 source characters, ordinary chat history included with a request is limited to the most recent 40,000 characters, and fetched images are limited to 10 MiB. Regex previews are limited to 1,000 matches and 100,000 output characters. Link-job session data uses a 7 MiB internal budget with result space reserved before a tab opens. Streaming responses from the side panel and archive page are capped at 2 MiB/200,000 characters, stop after two minutes total or 30 seconds without stream data, and can be stopped by the user.
  • Providing Personalized Features: Prompt templates help you quickly perform common tasks. Archiving and history features allow you to review important information.

Why Browser Permissions Are Requested

  • Compatibility: Version 1.4.0 requires Chrome 120 or later as the tested baseline for the side panel, session storage, alarms, and Web Worker workflow.
  • scripting: Run the requested page extractor in the tab you selected; page scope is controlled by host access.
  • tabs: Resolve the correct window/tab and create, monitor, then close the inactive temporary tab used for link extraction.
  • alarms: Enforce link-job timeouts, wake expired delivery leases/retries, and clean up records while the background service worker may be asleep.
  • storage: Save synced settings, local chat records, and temporary link jobs.
  • contextMenus and sidePanel: Provide link/image actions and the sidebar interface.
  • <all_urls> host access: Run extraction and optional selection/link features on pages you choose, and connect to OpenAI-compatible endpoints you configure. Host access alone does not transmit page content.

3. Information Storage and Security

  • Local Storage: Your conversation history, archives, and prompt templates are stored on your local computer using the chrome.storage.local API. This means the data does not leave your device unless you initiate an action that sends it to an AI service.
  • Sync Storage: Your API configurations, including API keys, are stored using chrome.storage.sync and may be synchronized across browsers signed into the same Google account. The developers cannot access this information. The extension adds no application-level encryption; the password input only obscures on-screen display.
  • Session Storage: A link job's URL, title, state, and extracted result are temporarily kept in chrome.storage.session, subject to a 7 MiB internal budget, so an opened sidebar can claim the result and the background can recover the job. Claiming does not delete the record. After a non-empty AI response completes successfully, the sidebar acknowledges and removes the job; if AI delivery fails, the claim is released and an alarm wakes a later retry. Any remaining completed or failed record is scheduled for cleanup about 10 minutes after extraction finishes; an active claim or retry delay postpones cleanup.
  • Security Measures: We follow industry-standard practices to protect your information. For example, the API key input field on the options page is a password field (type="password"). The extension also sanitizes model-generated Markdown with an HTML allowlist before display. It contains no code that sends your data to the developers.

4. Information Sharing and Disclosure

Chrome Web Store Limited Use: Data obtained through Chrome APIs is used only to provide or improve the extension's prominent user-facing features. It is not sold, used for advertising, transferred for credit or lending decisions, or accessed by humans except with the user's affirmative consent for security, legal compliance, or support. The extension's use and transfer of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

The extension developers do not sell your personal information or independently disclose it to unrelated third parties. When you invoke an online feature, your browser sends the data required for that feature to the AI provider, target website, or image host you selected.

The core working model of this extension is to act as a "bridge" between you and a third-party AI service. When you use this extension, you acknowledge that:

  • The data you request to be processed (such as web page content or text you type) and your API key are sent directly from your browser to the third-party AI service provider you have configured (e.g., Google or another OpenAI-compatible service).
  • A link summary causes the temporary background tab to visit the target website directly. That website handles requests, cookies, login state, and access logs under its own privacy policy.
  • These third-party service providers have their own independent privacy policies and data-handling practices. We strongly recommend that you review their privacy policies before use. This extension is not responsible for the data processing practices of any third-party service.

To reiterate, none of your data ever passes through our servers.

5. Your Rights and Choices

You have complete control over your information:

  • Access and Modify: You can view, modify, or delete your API configurations at any time on the extension's "Options" page. You can also manage your templates on the "Manage Prompts" page.
  • Local-Only Choice: You may use full visible-text extraction and regex preview/copy without configuring an AI API. Close the sidebar to stop selection capture.
  • Deletion:
    • You can permanently delete ordinary chat history using the "Clear All History" button in the sidebar. Archived conversations are not removed by that button.
    • You can delete individual archived chats or clear all archives on the "Archived Chats" page.
    • Uninstalling the extension will remove all data stored in chrome.storage.local (including history, archives, and templates).

6. Children's Privacy

This extension is not intended for use by children under the age of 13. We do not knowingly collect any personally identifiable information from children under 13.
